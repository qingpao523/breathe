# 呼吸 Breathe

呼吸法跟练 App：**方法即数据，证据透明，形状即方法身份**。
> 当前版本：`breathe-v1.3.apk`（包名 `com.qingpao.app`，versionName 2.0，minSdk 26 / targetSdk 34，debug 签名）。
> APK 放在**仓库根目录**，已被 `.gitignore` 忽略、**不入库**；本地重建：`python3 build_app.py`（需 Android SDK build-tools 34 + JDK）。

## 为什么做这个

市面 App 只告诉你吸几秒、屏几秒，不告诉你**这些数字从哪来**、证据多强。本项目把证据做进产品：每个内置方法标证据等级、论文出处、已知反证（见 `evidence/`）。

## 现在能做什么
- **四个板块**：减压 / 睡眠 / 运动 / 调息；方法卡带训练目标、档位推荐与证据星级。
- **8 个内置方法**：腹式呼吸、生理性叹息、共振慢呼吸 5.5、鼻腔呼吸训练、盒式呼吸 4-4-4-4、节奏呼吸（踏频耦合）、呼吸肌训练 IMT（说明卡，需器械）、CO₂ 耐受 / 屏息（含屏息安全筛查）。
- **描边式引导**：每个方法有固定形状（形状 = 方法身份，不按相位数）；一相 = 一条边，走完"边数 ÷ 相位数"个循环画出完整图形；相位切换永远落在顶点；屏息相位粉色虚线、呼吸相位青色实线；圆用 `arc`、多边形用 `lineTo`。详见 `docs/design-v3.md` §3。
- **目标模式**：按次数（3/6/10/20）、按时间（5/10/15/20 分钟）、自由（不限）；完成与退出分离；3 秒预备、可暂停、速度三档（标准 / 慢 ×1.35 / 更慢 ×1.7）。
- **成就系统**：每个方法 L1–L3（连练 3 / 5 次升档）、呼吸段位（每累计 30 分钟升一段）、累计次数与分钟、28 天热力图；**5 枚徽章**——习惯（任一方法 10 次）、熟练（总 100 次）、百次（单方法 100 次）、连续 7 天、全法·全开（全部可跟练方法各 ≥3 次）。
- **分享卡**：结算页生成 1080×1440（3:4）卡片，画本次方法的形状与练习时长，长按保存。
- **三通道引导**：视觉 + 声音（相位提示音：吸/补吸 520Hz、屏 660Hz、呼 330Hz、持 440Hz）+ 震动（相位切换 18ms）；另有屏幕常亮开关（安卓走原生桥）。
- **本地持久化**：设置、进度、徽章存 `localStorage`（键前缀 `breathe:`），刷新/重开不丢。
- **安卓包**：WebView 壳 + JS 桥（`vibrate` / `keepScreenOn` / `toast`），页面资源内置单文件 `index.html`。
- **专项**：骑行专区（骑前唤醒 / 骑行节奏呼吸 / 骑后恢复 / 关键时刻）。

## 方法即数据：现状与路线图

内置方法定义在 `web/index.html` 的两张表里：`METHODS`（方法数据）+ `SH`（方法 → 形状）。`methods/builtin/*.json` 是与内置方法对应的数据记录，供审阅与引用；**引擎目前不从 JSON 动态加载**，用户自定义表单 / 导入导出尚未实现（路线图）。要贡献内置方法，请先读 `CONTRIBUTING.md` 与 `methods/SCHEMA.md`。

## 单文件版

`web/index.html` 是完整可运行的单文件引擎（零依赖、零构建），浏览器直接打开即可用；仓库根目录 `index.html` 是同一份拷贝，便于 GitHub Pages 等静态托管。

## 结构

`evidence/` 证据库 | `methods/` 内置方法数据 | `web/` 单文件引擎 | `android/` 安卓壳与出包 | `docs/` 设计文档与踩坑记录（见 `docs/PITFALLS.md`）
