呼吸小程序 · 产品方案
v1 · 2026-09-23 · 微信小程序（个人主体）

呼吸一下：
跟着圆环呼吸的小程序

睡眠放松 + 运动训练双线并重，每节课都告诉你背后的证据。目标是自用先跑通，再给朋友用—— 所以这份方案的重点不是商业化，而是：哪些必须做、哪些平台不让你做、4 周怎么落地。

一页纸

先看四个关键判断

形态与类目
个人主体 ✓

可选「体育 > 在线健身」「工具 > 健康管理」，均无资质要求——不需要企业主体，也不用碰医疗资质。

发布路径
体验版先行

开发版/体验版可先给朋友用（加为体验成员）；正式对外发布前再完成小程序备案。

最大的技术风险
锁屏播放？

助眠场景依赖"锁屏后音频继续响"。这条必须在开工第一天验证，方案里已备好两级降级。

周期
4周

W1 技术验证 + 引擎移植，W2 能自己天天用，W3 能发给朋友，W4 上线体验版。

差异化

为什么值得自己做，而不是下一个现成的

自用产品不比全面，只需要三个"别人没有的理由"。

① 证据透明

每节课带一张"证据卡片"：出处、样本量、关键数字。国内没人这么做，而且直接复用调研成果，不用重新生产内容。

② 动效即节拍

方盒走方形轨道（屏息时停在角上）、4-7-8 走圆环、共振走连续波浪环——形状本身就是节拍的说明书。引擎已经在调研报告的 HTML 里跑通。

③ 运动线是空白

骑行节奏呼吸（吸 3 圈踏频/呼 2 圈）+ 鳄鱼式/90-90 姿态，现有产品没人做运动场景。调研有直接证据：声引导让呼吸-步频耦合率 26%→70%。

场景

"双线并重"落在四个场景上

不体现在首页入口数量，而体现在——睡前和骑车，各自都有完整的"进场-练习-收尾"。

场景触发时机时长技法组合成功信号
睡前关机22:30-23:30 躺下后10-20 分钟4-7-8（仪式）→ 共振 6 次/分一周 ≥4 晚完成
白天急救会议前、情绪上头1-2 分钟生理性叹息 ×5单日可多次触发
骑前唤醒出门前 / 上骑行台前3-5 分钟鳄鱼式呼吸 + 方盒 4-4-4-4骑行日必用

界面骨架

四个页面 + 一个全屏引导器

引导器是整个产品的价值所在——所有其他页面都只是为了让它被更省事地打开。

范围

MVP：P0 做到"自己每天都想打开"

P0 第 1-2 周

引导器引擎（方盒 / 4-7-8 / 共振 / 生理性叹息）；音频引导 + 后台播放；屏幕常亮；相位震动；本地记录；3 个快捷入口。

完成标志：睡前不用想、两步之内开始练。

P1 第 3-4 周

技法库扩到 12+（含瑜伽调息与运动组）；30 天睡前挑战；订阅消息提醒；分享卡片；记录页统计。

完成标志：发给朋友，对方能自己完成第一次练习。

P2 1-2 个月后

BLE 踏频/心率同步（圆环转速跟着踏频走）；鳄鱼式/90-90 姿态插画课；个人共振频率测试；云开发多设备同步。

明确不做（自用版边界）：社交/排行榜、社区、AI 生成课程、iOS 虚拟支付、多语言。

技术

小程序能力对照与第一验证项

需求方案注意点
圆环/方形动效canvas 2d + requestAnimationFrame小程序 WXML 不支持内联 SVG，圆环必须用 canvas；现有 demo 的相位状态机与路径参数化可直接移植
音频引导createInnerAudioContext + getBackgroundAudioManager⚠️ 后台/锁屏播放有限制 → 第一验证项
屏幕常亮wx.setKeepScreenOn(true)跟练必备；睡前场景要配合自动结束防耗电
触觉wx.vibrateShort({type:'light'})相位切换时触发；部分 iOS 机型不支持
提醒订阅消息（一次性订阅）长期订阅仅限特定类目，健康/运动类目拿不到 → 设计成"练完顺手订下一条"
本地存储wx.setStorageSync自用足够；P2 再上云开发
分享onShareAppMessage + canvas 海报挑战卡片、单次记录卡片
蓝牙（P2）BLE：踏频 0x1816 / 心率 0x180DiOS/Android 权限与稳定性有差异，放最后做
开工第一天要做的验证（半天出结论）——这是方案里唯一的高风险假设。

1. 后台音频：写 20 行 demo 播 10 分钟音频，测切后台 / 锁屏 / 息屏三种状态下是否继续（iOS + Android 各一遍），并确认 app.json 的 requiredBackgroundModes:["audio"] 声明要求。
2. 降级方案：Plan B = 屏幕常亮 + 音频 + 20 分钟自动渐弱停止（睡着后自己关）；Plan C = 助眠长音频放公众号音频/视频号，小程序只做提醒与跳转。
3. 帧率：中低端安卓机上测圆环动画，掉到 30fps 以下就降级成 CSS 动画。

落地

4 周做出可用的版本

W1
技术验证 + 脚手架 + 引擎移植。验收：锁屏播放结论明确；圆环在真机上跑起来。
W2
4 技法完整实现 + 音频 + 设置 + 本地记录。验收：自己能完成一晚睡前练习并留存记录。
W3
技法库 12 节 + 30 天挑战 + 提醒 + 分享卡片。验收：发给 3 个朋友，能独立完成一次练习。
W4
内容打磨 + 真机兼容 + 上线体验版。验收：体验成员 ≥5 人，连续使用 ≥1 周。
