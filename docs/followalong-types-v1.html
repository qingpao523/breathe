呼吸跟练类型规划 v1

结论先行：需要 7 种跟练引擎原型 + 1 个科普层（非跟练）。

28 种呼吸法不是 28 个产品类型——它们是 7 种原型的不同参数组合。

0. 先把问题问对：这里有三层「类型」，混用会毁掉规划

层回答的问题例子谁关心
用户层我什么时候用睡眠 / 减压 / 运动 / 调息用户（选择入口）
课程层这节课多长急救 1–2 分钟 / 日常 5–10 分钟 / 深度 15–20 分钟用户（选择成本）
引擎层跟随机制长什么样7 种跟练原型开发（工程量与扩展性）

「到底需要哪些跟练类型」问的是引擎层。它的答案决定：写多少个动效、新增技法要不要改代码、MVP 到底多大。

1. 第一性原理：跟练拆到不能再拆，只有 4 个基本要素

一个「跟练」＝ 用户跟着外部信号改变呼吸。拆解到不可再分：

要素 1 · 相位结构：吸 / 屏(满) / 呼 / 闭(空)——四相的有无、顺序、是否分段。 要素 2 · 时间形态：等长 / 比例化 / 连续无停顿 / 叠加分段 / 高频脉冲 / 递进斜坡 / 外部同步。 要素 3 · 节拍率：4.5 → 120 次/分，跨 27 倍（共振慢呼吸到圣光调息）。 要素 4 · 交互主体：引导的是「呼吸节拍」，还是「身体姿态」（鳄鱼式、90/90 的主体是膈肌感觉，呼吸只是背景）。

要素 1+2+3 决定 节拍引擎，要素 4 决定 渲染主体。四个要素的组合闭集，就是下面 7 种原型。

2. 七种跟练引擎原型

A｜等长轨（Equi-phase）

判别式：相位时长恒定，有明确停顿帧
覆盖：方盒 4-4-4-4、4-7-8、4-4-6 简化版、方盒进阶 6-6-6-6、Nadi Shodhana 交替鼻孔（+ 左右方向维度）
动效：方形/菱形轨道（形状即节奏，停在角上让屏息有天然的「到此一游」感）；4-7-8 用圆环 + 屏息倒计时（7 秒屏息配方形会让人等得不耐烦）
风险：低风险屏息（可归入安全层轻分诊）

B｜连续波（Sine / Coherent）

判别式：不存在屏息帧，吸呼连贯
覆盖：共振呼吸 5.5 / 6 次、睡前慢呼吸协议、失眠者节拍呼吸 0.1Hz、观呼吸（特例：无节拍，只观察计数）
动效：连续波浪环，不能有任何静止帧（出现停顿就破坏共振节律）
风险：无

C｜双段叠加（Double-inhale）

判别式：单个吸气周期内两次扩张
覆盖：生理性叹息、呵欠/叹息策略（同族，1–3 次即止）
动效：双段扩张（先扩一大步、再补一小步——「补吸」是它的辨识点）
风险：无。这是最快见效的急性减压，也是「急救档」唯一的实现方式

D｜高频脉冲（Pulse）

判别式：节拍率 \> 60 次/分，呼气主动用力、吸气被动
覆盖：Kapalabhati 圣光调息（60–120 次/分）、Bhastrika 风箱、Wim Hof 第一阶段（30 次快速呼吸）
动效：快速脉冲群 + 屏息计时环
风险：最高。禁忌：高血压 / 心脏病 / 癫痫 / 孕期 / 眩晕史；已有练习致气胸病例

E｜递进斜坡（Ramp）

判别式：某个参数（屏息时长 / 频率 / 次数）在会话内单调变化
覆盖：CO2 耐受与屏息训练（逐轮延长）、「找到你的共振频率」（6.5→4.5 每档降 2 分钟）、新手→进阶的渐进解锁
动效：计时环 + 台阶/进度
风险：高（屏息）

F｜外部同步（Sync）

判别式：节拍源不是内置计时器，而是踏频 / 步频 / 心率
覆盖：骑行节奏呼吸（吸 3 圈踏频 / 呼 2 圈踏频）、跑步 LRC（吸 3 步 / 呼 2 步）
动效：圆环转速与踏频同步
风险：无。这是「中国缺第二层」的差异化落点，也是唯一必须做实时输入的引擎

G｜姿态引导（Posture-led）

判别式：用户注意力对象是身体部位/动作，而非节拍
覆盖：鳄鱼式呼吸、90/90 呼吸、渐进式放松 + 呼吸、Dirga 三段式（分解动作）、身体扫描呼吸
动效：人体示意 + 腹部/肋部指示带，呼吸环仅作辅助
风险：无

科普层（非跟练）

缩唇呼吸（COPD 康复标准）、Buteyko、IMT 呼吸肌训练（器械）、腹式生物反馈（临床版）——只做科普卡片 + 遵医嘱，不进跟练课程流。

理由：它们是医学技法或需要器械，放进娱乐化课程流既是安全风险，也会稀释「证据透明」的定位。

4. 与既有设计逻辑的衔接（四维是横切的，不是类型）

7 种原型解决「跟随机制」。但产品上还有四个横切维度，它们不是类型，而是每个原型都要支持的属性：

场景：睡眠 / 减压 / 运动 / 调息 → 决定课程摆在哪个 Tab
时长档：急救 1–2 分钟 / 日常 5–10 分钟 / 深度 15–20 分钟 → 决定单课剂量
引导通道：视觉（默认） / 声音（跑步场景第一通道，耦合率 26.3%→69.9%） / 触觉（睡前闭眼场景第一通道）→ 每个原型都必须三通道可切
安全等级：无屏息 / 低风险屏息(4-7-8、方盒) / 高风险屏息(Wim Hof、CO2、圣光) / 医学技法(科普) → 屏息是唯一的分级开关，前置分诊挂在原型 A/D/E 上

用户在产品里只做两个选择：场景 + 时长。 技法由系统按场景和证据强度推荐——28 种技法直接摆给用户会造成选择过载，这是留存杀手。

5. 四条关键工程判断

不要做 28 个动画。 正确架构是：1 个相位时间轴引擎 + 7 个几何渲染模板 + 1 张技法配置表。
映射表成立 ⇒ 新增技法 = 加一行配置，零代码。 这是内容可扩展性的地基，也是这套规划最大的价值。
真实工程量集中在三处：① 连续波的平滑与音画同步（原型 B）② 外部同步的传感器输入（原型 F）③ 姿态引导的视觉资产（原型 G）。这三处恰好是原 MVP 六课里最重的三课。
原「6 课 MVP」的工程成本被低估了：它不是 6 个动画，而是 6 类引擎。建议按下节收敛。

6. MVP 范围建议

P0（先做，覆盖 4 种原型）

B 连续波 → 共振 5.5 + 睡前慢呼吸（养生主场景，证据最强）
A 等长轨 → 方盒 + 4-7-8（减压 + 助眠仪式）
C 双段叠加 → 生理性叹息（急救档，1 分钟）
G 姿态引导 → 鳄鱼式（运动预热，承接「骑行进化论」卡片一号动作）

P1（差异化高地，依赖传感器）

F 外部同步 → 骑行节奏呼吸（踏频耦合，中文市场空位）

P2（高风险 / 小众）

E 递进斜坡 → 屏息训练、CO2 耐受、共振频率寻优
D 高频脉冲 → Wim Hof、圣光调息（必须先做完备的安全分诊）

7. 待拍板

P0 是否接受从 6 课收敛为 4 课？ 我的判断是接受——6 类引擎同时开工会把第一版拖成两个月。
原型 F（踏频同步）放 P0 还是 P1？ 它是差异化核心，但也是唯一需要外部输入的一课；若你先要「自己每天想打开」，可以先 P1。
共振频率寻优（原型 E 的轻量版）要不要进 P0？ 它不需要传感器也能做「手动选一档」的简化版，性价比可能很高。
科普层是否独立成 Tab？ 还是只在课程详情页里作为「证据与安全」折叠区。
