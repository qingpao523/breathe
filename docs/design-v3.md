# 呼吸 App · 设计 v3（板块为门面 · 方法为数据 · 用户可扩展）
> 钉文档仅作一次性中转，导出后即落本地 MD 存档。   

## 0\. 一页纸

**做什么**：一个各种呼吸法的跟练 App，目标是提升呼吸能力本身。 **怎么讲给用户**：对外用**板块**讲"这是什么"，用**场景**讲"这有什么用"——用户不懂"通用"，也不需要懂。 **怎么实现**：对内是**一个通用引擎**（相位时间轴 \+ 3 种几何）\+ **一份方法数据**。 **差异化**：用户能自己添加方法；每个方法都标证据。

---

## 1\. 三层定位与市面对照

| 层 | 我们怎么做 | 市面谁做了 |
|---|---------------|---------------|
| **门面** | 板块（减压/睡眠/运动/调息）\+ 场景标签 | 潮汐、Calm、Now冥想 都有 |
| **能力** | 任意呼吸法跟练：预设 \+ **自定义** \+ 导入导出 | Paced Breathing、Awesome Breathing **已有** |
| **差异** | **证据透明**：每个方法标证据等级、出处、已知反证 | **没人做** |

**结论**：「自定义」不是差异点（十年前就有人做了），「证据」才是。

---

## 2\. 对外：四个板块

板块回答的是用户心里的那句话。

| 板块 | 用户心里的问题 | 内置方法 | 场景标签 |
|------|---------------------|------------|------------|
| **减压** | 我现在很紧张、心跳快 | **生理性叹息**（含补吸，最快见效）、盒式呼吸 4-4-4-4 | 会议前 / 情绪上头 / 急性重置 |
| **睡眠** | 我睡不着 | 共振慢呼吸 5.5、腹式呼吸 | 睡前 / 躺下后 |
| **运动** | 我要动起来了 / 刚动完 | **骑行专区**（骑前唤醒 / 骑行节奏 / 骑后恢复 / 关键时刻）、鼻腔呼吸、节奏呼吸、IMT | 训练前 / 行进中 / 运动后 |
| **调息** | 我想练更多传统技法 | 交替鼻孔、蜂鸣 | 探索线 |

**方法只写一次，板块是标签聚合出来的视图。** 共振慢呼吸只写一条，它同时出现在"睡眠"和"运动"（运动后恢复）——因为它的场景标签有两个。

## 3\. 对内：一个通用引擎

**相位时间轴**（引擎能表达 5 种，界面只暴露 4 种）：

| 相位 | 含义 | 谁在用 |
|------|------|---------|
| `inhale` 吸 |  | 全部 |
| `hold` 屏（满） |  | 方盒、4-7-8 |
| `exhale` 呼 |  | 全部 |
| `hold2` 持（空） |  | 方盒 |
| `**inhale2**` **补吸** | 第二段吸气 | **仅内置**（生理性叹息） |

**3 种渲染几何**：方形轨道（方盒类） / 圆环（屏息类） / 连续波（共振类，无静止帧）。

**2 种会话模式**（这是从市面抄来的关键一档）：
- **定时**：练完 N 个循环自动结束
- **自由练习**：不计时、不限循环，练到想停为止 —— Paced Breathing 与 Awesome Breathing 都有这一档，比强制练完 N 循环舒服得多

**3 个引导通道**：视觉（默认）/ 声音（跟着节奏）/ 触觉（相位切换震动，闭眼也能跟）。

## 4\. 方法即数据（用户可扩展的基础）
```json
{
  "name": "我的方盒 5-5-5-5",
  "phases": [
    { "k": "inhale", "s": 5 },
    { "k": "hold",   "s": 5 },
    { "k": "exhale", "s": 5 },
    { "k": "hold2",  "s": 5 }
  ],
  "cycles": 6,
  "mode": "timed",
  "meta": {
    "scene": ["减压", "专注"],
    "note": "比 4-4-4-4 更慢，适合晚上",
    "source": "自建",
    "safety": "low"
  }
}
```

**关键原则：格式的能力 ⊃ 表单的暴露面。** 引擎与格式支持 5 种相位，但用户表单只暴露 4 种 —— **复杂度留在内置内容里，不推给用户**。补吸只出现在生理性叹息这类内置方法中。

---

## 5\. 用户添加方法

**表单**（尽量少字段）：
```
名称        [我的方盒 5-5-5-5]
吸          [5] 秒      ← 0.5 秒精度
屏（可选）   [5] 秒
呼          [5] 秒
持（可选）   [5] 秒
循环次数     [6]        ← 或选「自由练习」
场景标签     [减压] [专注]
说明/出处    [选填]      ← 留空则显示「未标注来源」
```

保存即出现在方法库，可直接跟练。

**三层扩展路径**：

| 层 | 用户做什么 | 我们的能力 |
|---|---------------|---------------|
| L1 自建 | 表单新建，存本地 | 表单编辑器 \+ 本地存储 |
| L2 交换 | 导出 `.json` 分享 / 导入别人的 | 导入导出 |
| L3 回馈 | 看到新论文 → 自建 → 提 PR 进内置库 | GitHub 协作 |

**开源闭环在这里形成**：内置库是"经过证据审阅的方法集"，用户库是"个人实验田"，两者靠 JSON 流动。呼吸法一直在出新论文（你的调研里 2024–2026 就有 14 篇），靠一个人追不上 —— 让用户带着出处来添加，才可持续。

## 6\. 成就系统（累计次数 → 等级）

记录每个方法**累计练了多少次**，参考 1 万小时理论给等级：

| 等级 | 名称 | 累计次数 |
|------|------|------------|
| L1 | 起步 | 1 |
| L2 | 熟悉 | 3 |
| L3 | 习惯 | 10 |
| L4 | 稳定 | 30 |
| L5 | 熟练 | 100 |
| L6 | 精进 | 300 |
| L7 | 精通 | 1000 |

**几何增长 = 边际收益递减的可视化**：L1→L3 只要 10 次，L6→L7 要 700 次。

**连续天数不废除，但降级为展示指标**（反馈习惯），等级只由累计次数决定（反馈水平）——断一天不该清零。
> 市面印证：Breathe（顶空）就有 `session count log`，说明"累计次数"是行业共识。

## 7\. 从市面参考里抄来的三个细节

| 细节 | 出处 | 我们怎么用 |
|------|------|---------------|
| **free-form 会话**（不计时不限循环） | Paced Breathing、Awesome Breathing 都有 | 跟练页加"自由练习"档 |
| **练习次数记录** | Breathe 的 session count log | 成就系统的计量基础 |
| **内置 programs \+ 完全自定义并存** | Awesome Breathing（Box/Equal/Relaxing/Measured \+ 自定义） | 预设 8 个 \+ 用户可加 —— 你定的方向与市面成熟组合一致 |

---

## 8\. 差异清单（开源立项可直接用）
1. **证据透明**：每个内置方法标证据等级（★★★/★★）、论文出处、**以及已知反证**（如"4-7-8 生理证据弱、主观口碑强，定位仪式型"）—— 市面所有 pacer 都不做
2. **用户可添加 \+ 可交换 \+ 可回馈**：方法即数据，靠 JSON 流动
3. **补吸相位**：超出市面标准（Paced Breathing 只有吸/屏/呼），能表达生理性叹息
4. **自由练习模式**：不强制练完 N 循环

## 9\. 开源仓库结构
```
evidence/           ← 核心资产（CC BY 4.0）
  techniques.md        每个方法：节奏 / 证据等级 / 出处 / 已知反证
  papers-2024-2026.md  新论文清单（作者 / 年份 / 样本 / 效应量）
methods/            ← 方法数据（内置库，JSON，可被任何人引用）
web/                ← 单文件 HTML 相位引擎（MIT，可独立嵌入）
android/            ← 壳实现（诚实标注 WebView + 手工构建链路）
docs/               ← 设计文档（本文件 / 信息架构 / 成就系统）
```

**许可分离**：代码 MIT/Apache-2.0；**证据库与文档 CC BY 4.0**（论文整理的劳动成果要求署名）。

## 10\. 待定
1. **4-7-8 保不保留？** 它是 ★（生理证据最弱），按证据门槛该删；但主观助眠口碑最强。**建议保留为"仪式型"特例并明确标注** —— 这正好是"证据透明"最好的示范：诚实标出它的弱处。
2. **睡眠板块只有 2 个内置方法**（共振 5.5、腹式呼吸），会显得单薄。这恰好是"用户可扩展"的第一个真实用例 —— 用户看到新的睡眠论文，自己加进来。
3. **表单精度**：0.5 秒还是 0.25 秒？（Paced Breathing 用 0.25；0.5 更傻瓜）
