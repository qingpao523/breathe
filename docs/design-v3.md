# 呼吸 App · 设计 v3（板块为门面 · 方法为数据 · 用户可扩展）
> 钉文档仅作一次性中转，导出后即落本地 MD 存档。   

## 0\. 一页纸

**做什么**：一个各种呼吸法的跟练 App，目标是提升呼吸能力本身。 **怎么讲给用户**：对外用**板块**讲"这是什么"，用**场景**讲"这有什么用"——用户不懂"通用"，也不需要懂。 **怎么实现**：对内是**一个通用引擎**（相位时间轴 \+ 3 种几何）\+ **一份方法数据**。 **差异化**：用户能自己添加方法；每个方法都标证据。

---

## 1\. 三层定位与市面对照

| 层 | 我们怎么做 | 市面谁做了 |
|---|---------------|---------------|
| **门面** | 板块（减压/睡眠/运动/调息）\+ 场景标签 | 潮汐、Calm、Now冥想 都有 |
| **能力** | 任意呼吸法跟练：预设 \+ **自定义** \+ 导入导出 | Paced Breathing、Awesome Breathing **已有** |
| **差异** | **证据透明**：每个方法标证据等级、出处、已知反证 | **没人做** |

**结论**：「自定义」不是差异点（十年前就有人做了），「证据」才是。

## 2\. 对外：四个板块

板块回答的是用户心里的那句话。

| 板块 | 用户心里的问题 | 内置方法 | 场景标签 |
|------|---------------------|------------|------------|
| **减压** | 我现在很紧张、心跳快 | **生理性叹息**（含补吸，最快见效）、盒式呼吸 4-4-4-4 | 会议前 / 情绪上头 / 急性重置 |
| **睡眠** | 我睡不着 | 共振慢呼吸 5.5、腹式呼吸 | 睡前 / 躺下后 |
| **运动** | 我要动起来了 / 刚动完 | **骑行专区**（骑前唤醒 / 骑行节奏 / 骑后恢复 / 关键时刻）、鼻腔呼吸、节奏呼吸、IMT | 训练前 / 行进中 / 运动后 |
| **调息** | 我想练更多传统技法 | 交替鼻孔、蜂鸣 | 探索线 |

**方法只写一次，板块是标签聚合出来的视图。** 共振慢呼吸只写一条，它同时出现在"睡眠"和"运动"（运动后恢复）——因为它的场景标签有两个。

## 3\. 对内：一个通用引擎
> 本节按当前实现（`web/index.html`，HEAD `94c6fa8`）重写。核心一句话：**形状 = 方法的身份，不是相位数。**

### 3.1 相位时间轴

引擎能表达 5 种相位：

| 相位 | 含义 | 谁在用 |
|------|------|---------|
| `inhale` 吸 | 一段吸气，图形沿一条边前进 | 全部方法 |
| `inhale2` 补吸 | 第二段吸气 | 仅内置（生理性叹息） |
| `hold` 屏（满） | 屏住（满肺），画粉色虚线 | 盒式呼吸、CO₂ 耐受的梯级屏息 |
| `exhale` 呼 | 一段呼气 | 全部方法 |
| `hold2` 持（空） | 屏住（空肺），画粉色虚线 | 盒式呼吸 |
- 每个方法在 L1/L2/L3 各有自己的相位序列；CO₂ 耐受（co2）在每个循环末尾追加一次 `hold`，并且每循环 +5 秒（`ramp:{k:"hold",from:8,step:5}`）。
- 时长单位秒，支持 0.5 秒小数（内置共振 5.5 秒）；节奏呼吸（temp）用 `beats` × `bpm` 表达"吸 3 圈踏频 / 呼 2 圈踏频"。

### 3.2 渲染规则（以 `web/index.html` 的 `draw()` 为准）

渲染器不按相位数决定形状，而是每个方法一张固定的身份表：
```js
const SH={dia:0,nose:8,coh:4,sigh:3,box:4,temp:6,co2:3};
// 0 = 圆；3/4/6/8 = 正三/四/六/八边形的边数（顶点数 = 边数）
```

规则：
1. **一相 = 一条边。** 每个相位只走一条边，从当前顶点走到下一个顶点；相位结束正好落在顶点上，**相位切换不会停在边的中间**（`did=(cyc-1)*n+idx`、`ci=did%S`，`S=SH[id]`、`n` 是该档位相位数）。
2. **K = 边数 ÷ 相位数** 个循环画完一个完整图形；不能整除时，图形会在某个循环中途完成并从头重描。容易记错的一个：**coh 是 4÷2=2 个循环成正方形**（不是 4 轮）。
3. 顶点从正上方（-90°）开始、按 2π/S 均分（canvas 的 y 轴向下，视觉上为顺时针）；第 `k` 条边的颜色/线型取当前时间轴第 `k % n` 个相位的类型。
4. **屏息相位（`hold`/`hold2`）画粉色虚线**（`rgba(255,158,203,.85)`，7/13 dash）；**呼吸相位（`inhale`/`inhale2`/`exhale`）画青色实线**（已完成边 `#5ee0ff`，正在走的边 `#8fd0ff`）。未走到的边用 10% 白色底稿勾轮廓。
5. **圆的画法不同**：`SH[id]=0` 用 `arc` 画整圆（一个循环走完一圈，没有"边"的概念）；多边形用 `lineTo` 连边。
6. 画布每帧重绘，只画当前这一"圈"（S 条边）里已完成的边；跨过 S 的整数倍后从空图形重新描。

**方法 → 形状 → 相位数 → 几轮成图**（8 个内置方法全列）：

| 方法 | 形状 | 边数 S | 每循环相位数 n | 几轮成图 K=S/n |
|------|------|--------|--------------------|------------------|
| dia 腹式呼吸 | 圆（arc） | — | 2（吸 4 秒 / 呼 6 秒） | 1 轮 = 1 整圈 |
| sigh 生理性叹息 | 正三角形 | 3 | 3（吸 2 / 补吸 1 / 呼 6） | 1 |
| coh 共振慢呼吸 5.5 | 正方形 | 4 | 2（吸 5.5 / 呼 5.5） | 2 |
| nose 鼻腔呼吸训练 | 正八边形 | 8 | 2（吸 4 / 呼 4） | 4 |
| box 盒式呼吸 4-4-4-4 | 正方形 | 4 | 4（吸/屏/呼/持，L1 各 4 秒、L3 各 6 秒） | 1 |
| temp 节奏呼吸（踏频耦合） | 正六边形 | 6 | 2（吸/呼，按踏频 beats 计） | 3 |
| imt 呼吸肌训练 IMT | 无（说明卡片） | — | — | — |
| co2 CO₂ 耐受 / 屏息 | 正三角形 | 3 | 3（吸 4 / 呼 4 / 梯级屏息 8 秒起） | 1 |

**注意 1**：方法数据里的 `shape` 字段（square/ring/wave）是旧版展示标签，**渲染器不读它**；真正决定形状的是 `SH[m.id]`。新增方法必须同时在 `SH` 表里登记，否则按 0 退回圆。

**注意 2**：`imt` 是 `card:true` 且 `phases:[]`，只弹说明卡（需器械），不渲染图形、不计入练习。

### 3.3 目标模式

开始练习前可选三种目标（存本地设置，下次打开保留）：

| 目标 | 选项 | 停止条件 |
|------|------|------------|
| 按次数 | 3 / 6 / 10 / 20 次 | 完成设定循环数 |
| 按时间 | 5 / 10 / 15 / 20 分钟 | 计时到点自动结算 |
| 自由 | 不限 | 想停才停，HUD 显示已切换的相位数 |

**"完成"与"退出"分离**：完成走结算（计入累计次数/分钟/热力/徽章），退出不结算。开始前有 3 秒预备倒计时；练习中可暂停/继续，速度可选标准 / 慢（×1.35）/ 更慢（×1.7）。

### 3.4 三个引导通道
- **视觉**（默认）：上面的描边图形。
- **声音**：WebAudio 相位提示音 —— 吸/补吸 520Hz、屏 660Hz、呼 330Hz、持 440Hz，可关。
- **触觉**：相位切换震动 18ms（安卓走 `AndroidBridge.vibrate`，浏览器走 `navigator.vibrate`），可关。

另有"屏幕常亮"开关（安卓走 `AndroidBridge.keepScreenOn`）。

## 4\. 方法即数据（用户可扩展的基础）
```json
{
  "name": "我的方盒 5-5-5-5",
  "phases": [
    { "k": "inhale", "s": 5 },
    { "k": "hold",   "s": 5 },
    { "k": "exhale", "s": 5 },
    { "k": "hold2",  "s": 5 }
  ],
  "cycles": 6,
  "mode": "timed",
  "meta": {
    "scene": ["减压", "专注"],
    "note": "比 4-4-4-4 更慢，适合晚上",
    "source": "自建",
    "safety": "low"
  }
}
```

**关键原则：格式的能力 ⊃ 表单的暴露面。** 引擎与格式支持 5 种相位，但用户表单只暴露 4 种 —— **复杂度留在内置内容里，不推给用户**。补吸只出现在生理性叹息这类内置方法中。

## 5\. 用户添加方法

**表单**（尽量少字段）：
```
名称        [我的方盒 5-5-5-5]
吸          [5] 秒      ← 0.5 秒精度
屏（可选）   [5] 秒
呼          [5] 秒
持（可选）   [5] 秒
循环次数     [6]        ← 或选「自由练习」
场景标签     [减压] [专注]
说明/出处    [选填]      ← 留空则显示「未标注来源」
```

保存即出现在方法库，可直接跟练。

**三层扩展路径**：

| 层 | 用户做什么 | 我们的能力 |
|---|---------------|---------------|
| L1 自建 | 表单新建，存本地 | 表单编辑器 \+ 本地存储 |
| L2 交换 | 导出 `.json` 分享 / 导入别人的 | 导入导出 |
| L3 回馈 | 看到新论文 → 自建 → 提 PR 进内置库 | GitHub 协作 |

**开源闭环在这里形成**：内置库是"经过证据审阅的方法集"，用户库是"个人实验田"，两者靠 JSON 流动。呼吸法一直在出新论文（你的调研里 2024–2026 就有 14 篇），靠一个人追不上 —— 让用户带着出处来添加，才可持续。

## 6\. 成就系统（累计次数 → 等级）

记录每个方法**累计练了多少次**，参考 1 万小时理论给等级：

| 等级 | 名称 | 累计次数 |
|------|------|------------|
| L1 | 起步 | 1 |
| L2 | 熟悉 | 3 |
| L3 | 习惯 | 10 |
| L4 | 稳定 | 30 |
| L5 | 熟练 | 100 |
| L6 | 精进 | 300 |
| L7 | 精通 | 1000 |

**几何增长 = 边际收益递减的可视化**：L1→L3 只要 10 次，L6→L7 要 700 次。

**连续天数不废除，但降级为展示指标**（反馈习惯），等级只由累计次数决定（反馈水平）——断一天不该清零。
> 市面印证：Breathe（顶空）就有 `session count log`，说明"累计次数"是行业共识。

| 细节 | 出处 | 我们怎么用 |

## 8\. 差异清单（开源立项可直接用）
1. **证据透明**：每个内置方法标证据等级（★★★/★★）、论文出处、**以及已知反证**（如"4-7-8 生理证据弱、主观口碑强，定位仪式型"）—— 市面所有 pacer 都不做
2. **用户可添加 \+ 可交换 \+ 可回馈**：方法即数据，靠 JSON 流动
3. **补吸相位**：超出市面标准（Paced Breathing 只有吸/屏/呼），能表达生理性叹息
4. **自由练习模式**：不强制练完 N 循环


**许可分离**：代码 MIT/Apache-2.0；**证据库与文档 CC BY 4.0**（论文整理的劳动成果要求署名）。

## 10\. 待定
1. **4-7-8 保不保留？** 它是 ★（生理证据最弱），按证据门槛该删；但主观助眠口碑最强。**建议保留为"仪式型"特例并明确标注** —— 这正好是"证据透明"最好的示范：诚实标出它的弱处。
