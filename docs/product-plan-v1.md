# 呼吸小程序 · 产品方案 v1

> 2026-09-23 ｜ 形态：微信小程序（个人主体）｜ 目标：自用 + 小圈子先跑通
> 依据：《呼吸法全景调研》（同目录 `呼吸法DeepResearch.md`），本方案的每个功能决策都能追溯到那条调研结论

---

## 0. 一页纸

**产品名候选**：呼吸一下 / 一口呼吸 / 轻呼吸（暂用「呼吸一下」）

**一句话**：一个"跟着圆环呼吸"的微信小程序——睡眠放松与运动训练双线并重，每节课都告诉你背后的证据。

**用户**：你自己、骑行和健身的朋友、家人（10 人以内的熟人圈）。

**成功标准（自用版）**：连续 4 周、每周 ≥5 次练习；朋友圈子里 ≥3 人主动打开第二次。

**形态决策**：微信小程序，个人主体即可。
- 个人主体可选类目：**体育 > 在线健身**（"健身运动在线学习/在线指导"，无资质要求）或 **工具 > 健康管理**（健康记录类，无资质要求）——这是核对过官方类目表的结果，**不需要企业资质**。
- 自用+小圈子可以先走**开发版/体验版**（把朋友加为体验成员），不必等备案；要正式对外发布时，个人主体也能完成备案。

## 1. 差异化：为什么值得自己做，而不是下一个现成的

市面上的呼吸 App（Breathwrk、Calm、潮汐、Now冥想）已经很成熟，自用产品不需要全面竞争，只需要三个"别人没有的理由"：

**① 证据透明。** 每节课带一张"证据卡片"：这个技法的出处、样本量、关键数字（比如"6 次/分：84 人对照实验，HRV 增益显著优于方盒与 4-7-8"）。国内没有产品这么做，而这恰好是调研报告的直接复用——你不需要重新生产内容。

**② 动效即节拍。** 方盒呼吸走**方形轨道**（光点屏息时停在角上），4-7-8 走**圆环**（带屏息倒计时），共振呼吸走**连续波浪环**（无停顿）——形状本身就是节拍的说明书。这个引擎已经在调研报告的 HTML 里跑通了，可以直接移植。

**③ 运动线是国内空白。** 骑行节奏呼吸（吸 3 圈踏频 / 呼 2 圈）+ 鳄鱼式 / 90-90 姿态引导，是从骑行进化论那张卡片延伸出来的，现有产品没人做运动场景的呼吸训练。而且调研发现有直接证据支撑：声引导能把跑步呼吸-步频耦合率从 26.3% 提到 69.9%。

## 2. 用户与场景：双线并重怎么落地

"两线并重"不体现在首页入口数量上，而体现在**场景的完整性**上——睡前和骑车，各自都要有完整的"进场-练习-收尾"。

| 场景 | 触发时机 | 时长 | 技法组合 | 成功的信号 |
|------|---------|------|---------|-----------|
| **睡前关机** | 22:30-23:30 躺下后 | 10-20 分钟 | 4-7-8（仪式）→ 共振 6 次/分 | 一周 ≥4 晚完成 |
| **白天急救** | 会议前、情绪上头、心跳快 | 1-2 分钟 | 生理性叹息 ×5 | 单日可多次触发 |
| **骑前唤醒** | 出门前 / 上骑行台前 | 3-5 分钟 | 鳄鱼式呼吸 + 方盒 4-4-4-4 | 骑行日必用 |
| **骑后收尾** | 到家拉伸时 | 5 分钟 | 4-4-6 简化版 / 90-90 呼吸 | 骑行日必用 |

瑜伽调息（交替鼻孔、蜂鸣、三段式）作为**探索线**内容，不占核心场景，但它是内容纵深——这也是调研里"瑜伽调息是全品类内容库"的直接落地。

## 3. 功能架构

### 3.1 页面地图（4 个 Tab + 1 个全屏引导器）

```
首页
├── 今日推荐（按时间+场景自动切换的 1 张主卡）
├── 快捷开始（最近常练的 3 个技法，一键进入引导器）
└── 30 天睡前挑战 入口（进行中显示进度）

练习（技法库）
├── 睡眠组 / 减压组 / 运动组 / 调息组（四组分组）
├── 课程详情页（做法 + 证据卡片 + 安全提示 + 开始）
└── 全屏引导器 ← 核心页面
    ├── 圆环/方形动效 + 阶段提示 + 倒计时
    ├── 触觉与声音引导
    ├── 时长/循环调节（滑动改倍速：标准 / 慢 / 更慢）
    └── 结束页（本次记录 + 分享卡片 + 顺手订下一条提醒）

记录
├── 日历热力图（本月哪天练了）
├── 累计分钟数 / 连续天数
└── 技法分布（哪种练得最多）

我的
├── 提醒设置（睡前提醒 / 骑行日提醒）
├── 练习偏好（默认时长、声音、震动开关、屏幕常亮）
├── 证据来源说明（研究报告入口）
└── 免责声明（非医疗建议）
```

### 3.2 核心页面：引导器（整个产品的价值都在这一屏）

布局从上到下：
1. **顶部**：技法名 + 循环进度（3/6）
2. **中央**：大圆环 / 方形轨道 + 中心呼吸球 + 阶段文字（吸气/屏息/呼气）+ 秒数倒计时
3. **底部**：暂停 / 结束按钮（弱化，避免误触）
4. **结束页**：本次时长、完成了几个循环、一句鼓励语；「保存分享卡片」按钮（生成一张带呼吸数据的卡片，可发朋友圈/群）

关键交互细节（每条都有依据）：
- **相位切换震动一次**（`wx.vibrateShort` light）——闭眼跟练也能跟上节拍，这是触觉引导通道的最小实现；
- **慢速档**：把 4-7-8 放慢到 6-8-10 秒——调研发现"复杂节奏的依从率只有 74%"，新手需要降速入口；
- **进度可视化**：屏息阶段必须有倒计时数字（7 秒屏息干等是最劝退的环节）。

## 4. MVP 范围：P0 做到"自己每天都想打开"

| 优先级 | 内容 | 完成标志 |
|--------|------|---------|
| **P0**（第 1-2 周） | 引导器引擎（方盒/4-7-8/共振/生理性叹息 4 技法）；音频引导 + 后台播放；屏幕常亮；相位震动；本地记录；3 个快捷入口 | 你能在睡前不用想、两步之内开始练 |
| **P1**（第 3-4 周） | 技法库扩到 12+（含瑜伽调息与运动组）；30 天睡前挑战；订阅消息提醒；分享卡片；记录页统计 | 发给朋友，对方能自己完成第一次练习 |
| **P2**（1-2 个月后） | BLE 踏频/心率同步（圆环转速跟着踏频走）；鳄鱼式/90-90 姿态插画课程；个人共振频率测试（从 6.5 逐档降到 4.5）；云开发多设备同步 | 有人开始每周用 5 次以上 |

**明确不做**（自用版边界）：社交/排行榜、社区、AI 生成课程、iOS 虚拟支付、多语言。

## 5. 技术方案（微信小程序特定）

### 5.1 能力对照表

| 需求 | 方案 | 注意点 |
|------|------|--------|
| 圆环/方形动效 | **canvas 2d + requestAnimationFrame** | 小程序 WXML **不支持内联 SVG**，所以圆环必须用 canvas 画；现有 demo 的引擎逻辑（相位状态机、路径参数化）可以整体移植 |
| 音频引导 | `wx.createInnerAudioContext` + `wx.getBackgroundAudioManager` | **第一验证项**：后台/锁屏播放有限制（见 5.2） |
| 屏幕常亮 | `wx.setKeepScreenOn(true)` | 跟练期间必须开；睡前场景要防耗电（见 5.3） |
| 触觉 | `wx.vibrateShort({ type: 'light' })` | 相位切换时触发；iOS 部分机型不支持振动 |
| 提醒 | 订阅消息（**一次性**订阅） | 长期订阅只对特定类目开放，健康/运动类目拿不到 → 设计成"练完顺手订下一条" |
| 本地存储 | `wx.setStorageSync` | 自用够用；P2 再上云开发 |
| 分享 | `onShareAppMessage` + canvas 生成海报 | 挑战卡片、单次记录卡片 |
| 蓝牙（P2） | `wx.openBluetoothAdapter` + 踏频服务 0x1816 / 心率服务 0x180D | iOS/Android 权限与稳定性有差异，放最后做 |
| 视觉 | 暗色为主 + 半透明玻璃感 | 助眠场景必须暗色；canvas 用径向渐变+高光模拟玻璃质感 |

### 5.2 开工第一天要做的技术验证（半天出结论）

这是整个方案里**唯一的高风险假设**：助眠场景依赖"锁屏后音频继续播放"。

1. **后台音频验证**：写一个 20 行 demo，用 `getBackgroundAudioManager` 播放 10 分钟音频，测试：切到后台、锁屏、息屏三种状态下音频是否继续（iOS + Android 各测一遍）。同时确认 `requiredBackgroundModes: ["audio"]` 的声明要求与是否需要额外申请。
2. **降级方案**（如果锁屏播放不可用）：
   - Plan B：屏幕常亮 + 音频 + **20 分钟后自动渐弱停止**（用户睡着后自动关机，不吵也不耗电）；
   - Plan C：助眠长音频（30 分钟白噪音/引导）放到公众号音频或视频号里，小程序只做提醒和跳转。
3. **canvas 帧率**：在中低端安卓机上测圆环动画（目标 60fps，掉到 30fps 以下就降级为 CSS 动画）。

### 5.3 睡前场景的工程细节（容易踩坑）

- **默认 20 分钟自动结束**，最后 60 秒音量渐弱——防止睡着了还在播；
- 屏幕常亮要有上限（比如 30 分钟无操作自动恢复）；
- 每次进入引导器前记住上次的技法与时长，减少决策成本（睡前不适合做选择）。

## 6. 内容体系：课程表骨架

每节课的数据结构（五个字段）：`技法 / 建议时长 / 动效类型 / 音轨 / 证据出处`。下面是第一批 16 节课的骨架。

**睡眠组（4 节）**
| 课程 | 时长 | 动效 | 证据要点 |
|------|------|------|---------|
| 睡前慢呼吸 6 次/分 | 15 分钟 | 连续波浪环 | 30 天 PSQI 改善 d=0.51 |
| 4-7-8 助眠仪式 | 5 分钟 | 圆环+屏息倒计时 | 生理证据弱、主观口碑强 → 标"仪式型" |
| 4-7-8 慢速版（6-8-10） | 6 分钟 | 圆环 | 给屏息不适者 |
| 身体扫描呼吸 | 10 分钟 | 极缓慢呼吸球 | 正念呼吸，作为对照疗法 |

**减压组（4 节）**
| 课程 | 时长 | 动效 | 证据要点 |
|------|------|------|---------|
| 生理性叹息（急救） | 1 分钟 | 双段扩张 | 斯坦福 108 人，正性情绪提升最大 |
| 方盒 4-4-4-4 | 5 分钟 | 方形轨道 | 警察模拟研究：表现提升 |
| 4-4-6 简化版 | 3 分钟 | 圆环 | 无第二次屏息的温和版 |
| 方盒进阶 6-6-6-6 | 6 分钟 | 方形轨道 | 进阶解锁 |

**运动组（4 节）**
| 课程 | 时长 | 动效 | 证据要点 |
|------|------|------|---------|
| 骑前唤醒：鳄鱼式 + 方盒 | 5 分钟 | 姿态指导+方形 | 膈肌激活，骑行进化论卡片一号动作 |
| 90/90 呼吸 | 4 分钟 | 姿态指导 | 横膈膜-核心整合 |
| 骑行节奏呼吸 | 行进中 | 圆环随踏频 | 声引导耦合率 26%→70% |
| 骑后恢复 4-4-6 | 5 分钟 | 圆环 | 副交感恢复 |

**调息组（4 节，探索线）**
交替鼻孔 / 蜂鸣 / 三段式 / 清凉呼吸——全部标注传统来源与"研究样本偏小"的诚实提示。

**统一的安全层**：屏息类课程进入前弹一次筛查（孕期/癫痫/心血管/眩晕），命中任一项自动切换无屏息版本；所有页面底部固定"非医疗建议"声明。

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 锁屏播放不可用 | 助眠场景崩塌 | 第 1 天技术验证；备好 Plan B（常亮+渐弱自动停） |
| 类目/资质 | 发布阻塞 | 已确认：个人主体可选「体育>在线健身」「工具>健康管理」，无资质要求 |
| 备案 | 正式发布前置 | 体验版先跑；发布前完成备案（个人主体可备案） |
| 医疗宣称 | 审核 + 合规 | 全程用"放松/训练/练习"，禁用"治疗/治愈/改善失眠"等表述 |
| 屏幕常亮耗电 | 睡前体验 | 20 分钟自动结束 + 渐弱 |
| 订阅消息受限 | 提醒触达弱 | 一次性订阅 + 场景化引导（练完顺手订下一条） |
| 做完就吃灰 | 留存 | 30 天挑战 + 记录热力图 + 朋友圈分享卡（熟人监督最有效） |

## 8. 衡量指标（自用也要量，才知道有没有效果）

- 30 天挑战完成率
- 分享/邀请次数（小圈子的扩散信号）

## 10. 追溯表：每个功能都能找到它的证据

| 产品决策 | 依据（调研报告） |
|---------|----------------|
| 默认技法用 6 次/分共振呼吸 | Marchant 2025：HRV 增益显著优于方盒、4-7-8 |
| 保留 4-7-8 但标"仪式型" | Vierra 2022：生理指标不升反降；主观助眠口碑成立 |
| 生理性叹息做成 1 分钟急救课 | Balban 2023：5 分钟/天即有情绪收益，五组最高 |
| 新手第一课用简单节奏 | 依从率：6 次/分 90% vs 复杂节奏 74% |
| 睡前课设计成 15-20 分钟 | Laborde 2019：连续 30 天才出现 PSQI 与迷走活性改善 |
| 相位震动 | 触觉引导是闭眼场景的第一通道（Breathwrk/Calm 均有此设计） |
| 骑行节奏呼吸 + 踏频同步 | Harbour 2023：声引导使耦合率 26.3%→69.9% |
| 屏息类前置筛查 | Wim Hof 法有溺水死亡案例；Kapalabhati 有气胸病例报告 |
| 不做"治疗失眠"宣称 | 调研中所有证据均为"改善/辅助"，且个人主体类目不允许医疗宣称 |
